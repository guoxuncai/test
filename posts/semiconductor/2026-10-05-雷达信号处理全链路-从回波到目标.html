雷达信号处理全链路：从回波到目标

2026-10-05 跨领域拓展 · 第 23 篇 阅读约 17 分钟
这一篇要解决什么 黑夜里伸手不见五指，雷达却能告诉你 300 公里外有一架飞机、飞多快、往哪去、 甚至是什么机型——它不发光、不发热，靠的只是"喊一嗓子、听回声"。 这一篇沿着一条完整的信号流水线走一遍： 信号产生发射 → 天线接收回波 → 混入噪声杂波 → 模拟滤波 → ADC 采样 → 数字滤波与脉冲压缩 → MTI/MTD 多普勒滤波 → CFAR 目标检测 → 提取目标特征 → 算法模型识别 → 输出目标参数与类别。 读完你会明白：雷达的每一级都在回答同一个问题——怎么把淹没在噪声里的那一点回波，变成一个有名字的目标。

1. 直觉入门：蝙蝠的生存智慧

蝙蝠在漆黑的岩洞里高速飞行、互相不撞、还能精准捕蚊。它靠的不是眼睛，而是 回声定位：发出一声超声波尖叫，声波碰到蚊子反弹回来， 蝙蝠比较"喊"和"听"的时间差，就知道蚊子有多远；比较回声音调的变化，就知道蚊子正在接近还是远离。 这套机制有三个要素：主动发射、接收回波、从时间与频率差里提取信息。

雷达（Radio Detection and Ranging，无线电探测与测距）做的事情一模一样， 只是把声波换成了电磁波，把耳朵换成了天线。它的任务可以概括为三问：

问题雷达术语靠什么回答
有没有东西？检测（Detection）回波功率是否超过门限
在哪里、多快？参数估计（Estimation）回波时延、频移、到达角
它是什么？识别（Recognition）回波特征 + 算法分类

一个来自生活的类比：你对着山谷喊一声，2.9 秒后听到回声——声速 340 m/s， 山壁距离约 340 × 2.9 ÷ 2 ≈ 493 米（注意除以 2：声音走了一个来回）。 救护车驶近时警笛音调变高、远离时变低——这就是多普勒效应， 它泄露了目标的运动速度。雷达的全部魔法，都建立在这两个日常直觉之上。

2. 物理原理：时间换距离，频率换速度

2.1 测距：电磁波尺子

电磁波以光速 c = 3×108 m/s 传播，回波时延 τ 与目标距离 R 的关系为： R = c·τ / 2。除以 2 同样是"往返"修正。数字很惊人： 1 微秒的时延对应 150 米距离——雷达要在纳秒级精度上计时，才能做到米级测距。

更关键的是距离分辨率：两个目标要能被分开，回波时延至少差一个脉宽 τ， 即 ΔR = c·τ / 2。想让分辨率达到 15 米，脉宽得压到 0.1 微秒； 但脉宽越窄，脉冲携带的能量越少，探测距离就越近—— "看得远"和"分得开"在简单脉冲体制下是一对死敌。 这个矛盾要等到第 5 章的"脉冲压缩"才被漂亮地化解。

2.2 测速：多普勒频移

目标径向速度 v（朝雷达飞为正）会使回波频率偏移 fd = 2v / λ， 系数 2 来自"雷达与目标互为运动的收发双方"。代入感受一下： X 波段雷达波长 λ = 3 cm，一架 300 m/s 的战机带来 20 kHz 的频移—— 这个量级在射频里很小，却是数字信号处理最擅长捕捉的东西。

2.3 雷达方程：四次方根的残酷

回波功率由雷达方程决定： Pr = PtG²λ²σ / [(4π)³R⁴]。最刺眼的是 R⁴—— 距离翻倍，回波只剩 1/16。想靠加大功率把探测距离翻倍，功率得加到 16 倍。 这就是为什么雷达工程师对"每一分信噪比"都锱铢必较，也是后面一长串处理增益存在的原因。

方程里的 σ 是雷达散射截面积（RCS）：目标"看起来有多大"。 它与几何尺寸并不成正比——大型轰炸机约 10–100 m²，战斗机 1–10 m²， 而精心外形的隐身战机可低至 0.01 m² 量级（外形散射+吸波材料双重压制）。 隐身与反隐身的攻防，本质上就是围绕这个 σ 的持续军备竞赛。

4. 模拟前端：在"最脏"的世界里先活下来

4.1 波形产生与发射：干净的开始

一切从波形产生器开始：晶体振荡器提供极其稳定的基准频率 （秒级漂移仅 10-11 量级——这是全相参体制的根基）， 频率综合器在其上生成载波，再由波形存储器输出预先设计好的调制波形 （简单脉冲、线性调频 LFM、相位编码等）。 发射机随后把这份"温和"的小信号放大到千瓦甚至兆瓦级—— 老式雷达用磁控管（一个管子包办振荡+放大，但波形不可控）， 现代雷达用全相参固态发射：每个收发组件（T/R module）独立放大， 波形、相位完全可控。相控阵雷达把上千个 T/R 组件铺成阵列， 靠控制每个组件的发射相位让波束"电扫"——机械转动一个自由度都不需要。

4.2 天线接收回波：弱势群体的诞生

发射结束后天线切换到接收（收发开关 T/R duplexer 防止大功率烧毁接收机）。 此刻回波有多弱？发射 1 MW、目标 200 km 外、RCS 5 m²—— 按雷达方程算回来，回波功率约 10-15 瓦量级， 比发射弱了 1018 倍（180 dB）。接收机的第一级是 低噪声放大器（LNA），它的噪声系数几乎决定了整个系统的灵敏度—— 这也是为什么雷达 T/R 组件的 GaN LNA 是兵家必争之地（与本站 《半导体材料全景》中 GaN 的高功率密度特性直接呼应）。

4.3 噪声与杂波：两种完全不同的"坏人"

回波在路上和机器里被两类干扰污染，性质截然不同：

类型来源统计特性对抗手段
噪声电阻热、接收机内部宽带、不可预测、功率低（kTB，毫微瓦级）滤波、累积、处理增益
杂波地物、海面、云雨、鸟群强相关、多普勒集中于零频附近、功率可高出噪声 60 dB 以上动目标处理（MTI/MTD）

这个区分是全篇最重要的概念之一：噪声是"随机背景"，杂波是"缓慢的同伙"—— 它们听起来都是干扰，但统计行为完全不同，所以后面的数字处理会用两种完全不同的武器分别对付。

4.4 模拟滤波与 ADC：模拟世界的交接仪式

下变频到中频后，模拟滤波做两件事：带通滤波选出信号信道、 抑制邻道干扰；抗混叠低通保证进入 ADC 前带宽受限。 然后 ADC 完成模拟到数字的不可逆交接。两个关键参数：

  • 采样率：奈奎斯特定理要求 fs ≥ 2B（B 为信号带宽），否则频谱折叠、信息永久损失。带宽 B 同时决定了距离分辨率 ΔR = c/2B——带宽就是分辨率，分辨率就是采样率，采样率就是钱。
  • 量化位数：12 bit 动态范围约 72 dB，14 bit 约 84 dB。为什么需要这么大？因为杂波可比弱目标强几万倍——位数不够，强杂波直接把 ADC 顶到饱和，弱目标连被量化的机会都没有。高动态范围 ADC 是雷达数字化的核心瓶颈之一。

从 ADC 输出那一刻起，信号变成一串复数样本，物理世界退场，数学登场。

5. 数字处理三部曲：脉冲压缩、MTI/MTD、CFAR

5.1 脉冲压缩：鱼与熊掌的和解协议

第 2 章留下的死结——窄脉冲分辨率高但能量小——由脉冲压缩解开。 思路堪称优雅：发射一个宽脉冲（能量足、传得远），但让它的频率在脉宽内 线性扫过一大段带宽（线性调频 LFM）。接收端用匹配滤波器处理—— 数学上就是与发射波形的副本做相关：波形内部各处与副本相关得参差不齐， 唯有对齐时刻相关值叠加出一个又窄又高的峰。

效果：测距分辨率由带宽决定（ΔR = c/2B，B = 100 MHz → 1.5 米）， 探测能量由脉宽决定（τ = 100 μs），两者彻底解耦， 处理增益约为时宽带宽积 BT（本例 10⁴，即 40 dB）。 实现上不必逐点做相关——用 FFT 把信号变到频域乘上匹配谱再变回来 （快速卷积），工程上就是一块 DSP/FPGA 的日常。 唯一的副作用是距离旁瓣：强目标的旁瓣可能盖住旁边的弱目标， 常用加窗（Hamming/Taylor）压制到 −40 dB 以下，代价是主瓣略微展宽、 信噪比损失 1–2 dB——雷达工程里"没有免费午餐"的又一次体现。

5.2 MTI/MTD：利用速度 signatures 区分敌我背景

杂波（地物、山）是静止的，多普勒为零；飞机是动的，多普勒非零—— 这就是动目标显示（MTI）的全部依据。两脉冲对消器把相邻两个脉冲重复周期的 回波相减：静止杂波每个周期都一样，相减归零；运动目标的回波相位在周期间持续变化， 相减后有剩余。继续升级：三个脉冲双对消、再叠加反馈，杂波抑制可达 40 dB 以上。

MTI 的软肋是盲速：当多普勒频移恰好等于脉冲重复频率 PRF 的整数倍时， 相邻周期相位差为零，动目标被当成杂波一起对消（这就是骑自行车的人速度恰好"对消"时会从屏幕上消失的原因）。 工程解法是参差 PRF（周期间故意不等间隔，让盲速错开）。 更现代的方案是MTD（动目标检测）：在一个相干处理间隔（CPI）内对同一距离门的 多个脉冲做 FFT，得到一组多普勒滤波器组——静止杂波掉进零频滤波器， 不同速度的目标各占一个滤波器，配合杂波图自适应选择通道。MTD 本质上是 "MTI + 多普勒滤波 + 杂波图"三位一体的框架，是 20 世纪 70 年代以后雷达的标配。

5.3 CFAR：承认不知道噪声多大，就让门限自己学

经过脉冲压缩与 MTD，信噪比已经大幅改善，现在要回答"有没有目标"。 检测的本质是设门限：信号超过门限判为目标。门限定多高是个两难—— 定低了虚警（把噪声当目标，系统被假目标淹没），定高了漏警（错过真目标）。 更麻烦的是噪声与杂波功率随环境变化达几个数量级：固定门限在 clean 环境合适， 进了强地物区就满屏虚警。

恒虚警（CFAR）的答案：门限不是常数，而是随环境实时自适应。 最经典的单元平均 CA-CFAR（图 2 右）：在待检测单元两侧各取一排 参考单元估计当前本底功率，乘上系数 α 得到门限—— 本底强则门限自动抬高，本底弱则自动降低，虚警概率保持恒定。 两个工程细节见功力：参考单元与待检单元之间隔 1–2 个 保护单元，防止目标能量泄漏进参考集、把自己的门限垫高； 杂波边缘和多目标场景下 CA-CFAR 会失灵，改用有序统计 OS-CFAR （对参考单元排序后取第 k 大，天然抗野值）。 CFAR 的代价是 CFAR 损失：用有限个样本估计噪声本底不如真值准， 等效于损失约 1–3 dB 信噪比——用一点检测灵敏度，换全环境虚警可控，划算。

6. 从检测到识别：给毛刺一个名字

6.1 点迹 → 航迹：时间维度的第二次增益

CFAR 输出的是一个个孤立的点迹（某距离、某方位、某速度上有个东西）。 下一步是把跨扫描周期间的点迹串成航迹：先做数据关联 （新点迹和已有航迹预测位置作比较，最近邻或全局最近邻算法），再用 跟踪滤波器平滑估计——经典的 α-β 滤波到卡尔曼滤波， 机动目标则用交互多模型（IMM）在"匀速"与"机动"假设间软切换。 航迹还解决了一个隐蔽问题：单帧的虚假点迹下一帧对不上，会被"航迹起始/终止"逻辑自然淘汰—— 时间维度的关联，本身就是一次免费的虚警过滤。

6.2 特征提取：回波里的指纹

确认了"有个目标"之后，识别需要特征。雷达回波可提取的"指纹"相当丰富：

特征物理来源能区分什么
运动参数位置、速度、航向、加速度飞行剖面：客机巡航 vs 战机机动
RCS 及其起伏目标尺寸、外形、姿态角大目标 / 小目标；起伏周期反映结构
微多普勒旋翼、发动机叶片、人体肢体的微运动直升机（叶片调制线谱）vs 固定翼；步态识别人
高分辨距离像（HRRP）宽带波形下各散射中心的距离分布目标长度与结构骨架
ISAR 二维像目标自转 + 宽带合成孔径二维轮廓，接近"照片"级

微多普勒尤其巧妙：直升机的旋翼在主体运动之上叠加周期性微运动， 在多普勒谱上形成特征的调制边带——像一个声音签名。 人走路的肢体摆动同样在谱上留下"步态纹"，远距离非接触识别行人的研究正基于此。

6.3 算法识别：从模板匹配到深度学习

有了特征，分类器接管。传统路线是特征工程 + 浅层模型： 手工设计统计特征（谱熵、旁瓣结构、尺寸估计），再用决策树、SVM 或最近邻做模板匹配—— 可解释性强、小样本友好，至今仍是主用体制。现代路线是深度学习： 一维 CNN 直接吃 HRRP 序列，二维 CNN 处理 ISAR 像或多普勒谱图， 循环/注意力结构处理微多普勒时序——在公开数据集上，识别率普遍越过 95%。 但雷达识别有两大独特难点：样本稀缺（真实军机回波密不可得， 仿真数据与现实存在域差距）与可信度要求（把民航机误判为威胁的代价不可承受）， 所以工程上深度学习常以"置信度输出 + 人工复核"的辅助角色落地。 另有一条独立的硬通道不能忘记：敌我识别（IFF）——询问机发出加密询问， 己方应答机回答，配合雷达航迹使用。算法再好，也替代不了这一条制度性通道。

6.4 输出：一个目标的完整档案

流水线的终点不是"滴滴"一声，而是一份结构化档案： 目标批号、斜距 / 方位 / 俯仰（或经纬度与高度）、径向速度、航向航速、 RCS 估计、类别与置信度，随后送往显示器、指挥系统与数据链。 从 10-15 瓦的一缕回波到这份档案，整条链路历经十一级， 每一级都贡献了属于自己的那几分贝。

7. 工程边界、易错点与自测

7.1 这套链路的边界在哪里

  • 模糊问题：PRF 高了测速不模糊但测距模糊（远目标回波"迟到"被算近），PRF 低了反之——距离-多普勒模糊是体制级权衡，参差 PRF / 多 PRF 交错解算只是缓解而非消除；
  • 低角与海杂波：掠海目标与海面杂波在角度上不可分，海尖峰杂波非高斯，CFAR 与 MTD 都会退化——反舰导弹末段探测至今是难题；
  • 隐身与电子战：RCS 压缩 30 dB 意味着探测距离缩到 18%，防御方以低频雷达（隐身外形对低频失效）、多基地（从侧面看 σ 大）反制；干扰与抗干扰（捷变频、旁瓣对消、波形捷变）是永不落幕的博弈；
  • 与半导体行业的联系：AESA 相控阵的 GaN T/R 组件、高动态范围 ADC、FPGA/GPU 实时处理——现代雷达的军备竞赛已完全落在宽禁带半导体与数字芯片上，与本站《半导体材料全景》《存储器》多篇内容互为注脚。

7.2 三个常见误区

  • "雷达测的是反射，目标反射越强越容易发现"：检测看的是信噪比而非绝对回波强度——强杂波背景里的大目标，可能不如干净背景里的小目标好检；
  • "脉冲压缩让回波变强了"：回波本身没变，是处理把分散在宽脉冲里的能量重新聚焦成一个窄峰——能量守恒，分布改变了而已；
  • "CFAR 检测出的一定是目标"：CFAR 只保证虚警概率恒定，不保证为零——每次检测都有虚警率，航迹关联再兜底；恒虚警 ≠ 无虚警。
自测 1：脉冲压缩为什么能同时做到"看得远"和"分得开"？代价是什么？
发射宽脉冲保能量（看得远），脉内调频展宽带宽，接收端匹配滤波把宽脉冲 相关聚焦成 1/B 的窄峰（分得开，ΔR=c/2B）——能量与分辨率解耦，增益约 BT。 代价是距离旁瓣：需加窗压制到 −40 dB，付出主瓣展宽与 1–2 dB 信噪比损失。
自测 2：MTI 为什么能消地物杂波？"盲速"是怎么产生的、如何缓解？
静止杂波相邻周期回波完全相同，两脉冲相减归零；动目标相位周期间变化，相减有剩余。 当多普勒频移恰为 PRF 整数倍时，相邻周期相位差为零，动目标被当杂波对消——即盲速。 缓解：参差 PRF 使盲速点错开，或改用 MTD 多普勒滤波器组直接在频域分离。
自测 3：CFAR"恒虚警"的代价是什么？保护单元起什么作用？
用有限参考单元估计噪声本底，估计误差等效损失约 1–3 dB 信噪比（CFAR 损失）， 且杂波边缘处估计失真会造成虚警尖峰或漏检。保护单元隔开待检与参考单元， 防止目标能量泄漏进参考集抬高本底估计、把"自己"的门限垫高导致漏检。
自测 4：雷达 ADC 为什么需要 12–14 bit 的高位数？位数不足会发生什么？
杂波可比弱目标强 60 dB（几千到几万倍），ADC 动态范围必须容纳强杂波。 位数不足时强杂波占满量化区间甚至饱和，弱目标的量化层次被吞掉—— 信号还在，但信息已被"削顶"，数字域再强的算法也无法恢复。
自测 5：为什么说现代雷达的竞争"一半在半导体"？举出至少两个器件层面。
① GaN/SiC 功率器件：AESA 每个 T/R 组件的功放与低噪放，GaN 高功率密度 直接提升发射功率与接收灵敏度；② 高动态范围 ADC：决定数字化的信息上限； ③ FPGA/GPU/专用 DSP：脉冲压缩、MTD、CFAR 的实时算力载体。 每一 dB 的系统性能，最终都落到半导体器件的某一参数上。
