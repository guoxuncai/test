1. 先建立直觉：有序 vs 无序

同样都是硅原子，排列方式不同，性质天差地别。三类固体要先分清：

为什么"周期性"这么重要？能带理论的前提就是原子排列具有平移周期性。 只有在周期势场中，电子的波函数才能写成布洛赫波、能量才会分裂成允带和禁带。 一旦出现晶界、位错、杂质团簇，周期性被打破，就会在禁带里引入能级 —— 这正是漏电和复合的来源。 所以从晶体学开始学，是理解后面所有内容的唯一正确入口。

2. 晶格与晶胞：点阵 + 基元

晶体学最核心的一个公式（不是数学公式，是构造公式）：

晶体结构 = 空间点阵（Lattice）+ 基元（Basis / Motif） 点阵回答"周期怎么重复"，是纯几何的抽象点阵；基元回答"每个点上放什么"，是具体的原子（可以是一个，也可以是一组）。 同一个点阵配不同基元，得到完全不同的物质 —— 这一点在金刚石 vs 闪锌矿上体现得淋漓尽致。

3. 三种立方晶胞：SC / BCC / FCC 与堆积密度

金属和半导体里最常见的是三种立方晶胞。它们的核心差别是原子在晶胞里放了几个、放在哪， 由此决定了配位数和堆积密度。

APF = N · (4/3)π r³ / a³　（堆积率 = 原子总体积 / 晶胞体积） SC：N=1，r=a/2 → π/6 ≈ 52%。BCC：N=2，r=√3a/4 → √3π/8 ≈ 68%。 FCC：N=4，r=√2a/4 → √2π/6 ≈ 74%（最密堆积）。金刚石：N=8，r=√3a/8 → √3π/16 ≈ 34%（非常"空"）。
记住金刚石只有 34% 的堆积率 —— 硅晶体内部非常"空旷"， 这正是杂质原子能挤进晶格间隙（间隙式扩散）、以及离子注入能把原子塞进去的物理基础。 这个数字在第 13 篇讲掺杂工艺时会再次用到。

5. 晶向 [uvw]：三步求出一个方向

晶向指数 [uvw] 用来标记晶体中的方向。求法只有三步：

  1. 平移：把待求方向平移到过原点（晶体中平行方向等价，可以随便移）；
  2. 取点：在该方向上任取一点，读出它的坐标 (x, y, z)，单位是晶格常数 a；
  3. 化整：三个坐标同除以最大公约数，化为最小整数比，写成 [u v w]。负值在数字上方加横线。
例：过点 (1, 0, 0) → [100]　｜　过 (1, 1, 0) → [110]　｜　过 (1, 1, 1) → [111]　｜　过 (1, 0, −1) → [101] 负号不能写成 −1，必须写成上划线：[1̄01] 记为 [101]。这是书写规范，考试和论文都认这个。

5.1 晶向族 <uvw>

由于立方晶系的对称性，很多晶向是完全等价的（原子排列一模一样），只是方向不同。 把它们打包记作尖括号 <uvw>：

<100>[100] [010] [001] [1̄00] [01̄0] [001̄] —— 共 6 个等价方向（±3 个轴）
<110>[110] [101] [011] [11̄0] … —— 共 12 个（面对角线方向）
<111>[111] [1̄11] [11̄1] [111̄] … —— 共 8 个（体对角线方向）

6. 晶面 (hkl)：米勒指数怎么来的

晶面指数（米勒指数）(hkl) 标记一族平行的原子平面。求法也是三步，但要先取截距再取倒数：

  1. 求截距：找出晶面与 x、y、z 三个晶轴的截距，用晶格常数 a 为单位表示（如 1, 1, ∞）；
  2. 取倒数：1/截距 → 1/1, 1/1, 1/∞ = 1, 1, 0；
  3. 化整：化为最小整数比，写成 (h k l)。与轴平行 → 截距 ∞ → 指数 0；负截距 → 数字上加横线。
为什么非要取倒数？两个原因：① 让"与轴平行"这种常见情况有简洁表示（0，而不是 ∞）； ② 更深层的原因 —— 米勒指数 (hkl) 的整数，恰恰等于该晶面法向量在倒格子基矢下的坐标。 所以取倒数不是人为规定，而是为了指数能直接反映晶面的取向与面间距。

6.1 面间距公式

dhkl = a / √(h² + k² + l²)　（仅立方晶系） 硅（a = 5.431 Å）：d₁₀₀ = 5.431 Å，d₁₁₀ = a/√2 = 3.840 Å，d₁₁₁ = a/√3 = 3.135 Å。 注意：指数越大，面间距越小，这是 XRD 谱峰位置的基础。

7. 面密度、线密度与悬挂键：数字背后的物理

这三个"密度"是把晶体学和器件物理连起来的桥梁，也是考题与工程判断的常客。

面密度
（planar density）		单位面积上的原子数，atoms/cm²。决定氧化速率、外延速率、界面态密度
线密度
（linear density）		某晶向上单位长度的原子数。决定位错滑移方向、扩散各向异性
悬挂键密度晶体被切开后，表面原子未配对的价键数/cm²。决定表面态与界面质量

7.1 硅三个主晶面的面密度（要求会算）

Si(100)：2 / a² = 6.78×10¹⁴ cm⁻²　｜　Si(110)：2√2 / a² = 9.59×10¹⁴ cm⁻²　｜　Si(111)：4 / (√3 a²) = 7.83×10¹⁴ cm⁻² 取 a = 5.431 Å ⇒ a² = 2.95×10⁻¹⁵ cm²。计算思路：数出晶面在一个二维重复单元里有几个原子，除以该单元面积。 注意顺序：(110) > (111) > (100) —— 面密度最高的是 (110)，不是 (111)。
理想未重构表面悬挂键密度：(100) 每原子 2 个 → 1.36×10¹⁵；(111) 每原子 1 个 → 7.83×10¹⁴ cm⁻² 实际 Si(100) 表面会发生 2×1 重构（二聚化 dimerization）：相邻两个原子两两配对， 悬挂键数减半到 6.78×10¹⁴ cm⁻²。这是表面物理的经典案例 —— 表面会自发"修复"自己以降低能量。
这里有个容易记混的反直觉点：(100) 面的面密度最低（6.78×10¹⁴）， 但它的Si/SiO₂ 界面态密度也最低（约 10¹⁰ cm⁻²·eV⁻¹，比 (111) 低约一个数量级）。 原因是界面态密度不只取决于原子数，更取决于氧化时悬挂键的匹配方式与应变： (100) 面上每个 Si 有两个悬挂键，氧化时更容易形成完整的 Si–O–Si 桥接网络； 而 (111) 面原子排列最密、氧化速率最快，反而容易产生更多未饱和键与应变缺陷。 结论：做 MOS 选 (100)，这是实验事实驱动的选择。

9. 晶向如何决定器件性能（本篇重点）

这是本篇最需要记住的一节 —— 晶向不是考试题，它直接写进工艺规格书。

10. 各向异性刻蚀：54.74° 与倒金字塔

湿法刻蚀里最漂亮的一个例子：用 KOH 溶液刻 (100) 硅片，不会得到圆弧坑，而是得到四个 (111) 面围成的倒金字塔。 原因是 (111) 面原子密度最高、每个原子可参与反应的键最少，刻蚀速率极慢，成为"自停止面"。

11. 倒格子与布拉格衍射：晶向是怎么测出来的

我们说"这块硅片是 <100>"，这句话是怎么被测出来的？答案是 X 射线衍射（XRD）。 背后的原理是布拉格定律：把晶面族看成一组间距为 d 的平行反射面， 只有相邻面反射的波程差恰好是波长整数倍时才相干加强。

2 dhkl · sin θ = n λ　（布拉格定律） θ 是入射线与晶面的夹角（不是与法线的夹角！这是最常见的错点）。 固定波长 λ、扫描角度 θ，出现衍射峰的位置就对应某个 dhkl，反查即可知晶面族与晶向。
顺便建立"倒格子"的直觉：真实空间的晶面族 (hkl) ↔ 倒格子中的一个点 (hkl) 矢量， 该矢量的方向就是晶面法向、长度等于 1/dhkl。 所以在倒空间里，"晶面"变成"点"，衍射图样本质上是倒格子的投影 —— 这也是为什么米勒指数要取倒数：它天生就是倒空间坐标。

13. 晶向与版图：匹配设计为什么要求同方向

这一节把晶体学和前面/后面的内容接起来。模拟版图里有条铁律： 需要匹配的两个器件必须同尺寸、同形状、同方向、同环境。其中"同方向"的根源就是晶向。

  1. 迁移率各向异性：电子/空穴迁移率随晶向变化。两个 MOS 管沟道方向差 90°， 即使 W/L 完全相同，μ 也不同 → 电流失配；
  2. 应力各向异性：STI（浅沟槽隔离）和金属层会带来机械应力， 硅的弹性常数是各向异性的 → 压阻效应使不同方向器件受力后迁移率变化不同；
  3. 工艺微负载：刻蚀、注入（尤其倾斜注入与沟道效应）都随晶向变化。 离子注入的沟道效应正是沿低指数晶向（如 <110>、<111>）原子排列"看过去是空的"，离子可以长驱直入；
  4. 解法：所有匹配器件同方向摆放 + 共质心（common-centroid）对称布局 + Dummy 器件保证边缘环境一致（详见第 17 篇：版图设计实战）。
离子注入的"沟道效应"值得单独记：沿 <110> 方向看金刚石结构， 原子排列形成一条条"通道"，注入离子如果正好沿通道入射，射程会远大于设计值，导致结深远超预期。 工程解法：注入前把硅片倾斜 7° 左右，让离子避开通道方向；或先做预非晶化（PAI）层打乱晶格。 这是"晶向知识直接决定工艺参数"的典型例子。

14. 常见误区

误区 1：认为 [hkl] 一定垂直于 (hkl)。 这只对立方晶系成立。六方、四方等晶系中，[hkl] 与 (hkl) 一般不垂直 —— 必须用法向量计算。
误区 2：把晶面指数当成"坐标"。 (hkl) 描述的是一族平行平面，不是单个平面；且指数取的是截距的倒数， (200) 与 (100) 平行但面间距差一半（d₂₀₀ = a/2），XRD 里是两个不同的峰。
误区 3：以为面密度最高的是 (111)。 硅的顺序是 (110) 9.59 > (111) 7.83 > (100) 6.78（×10¹⁴ cm⁻²）。 最"密排"的排列是 (111) 的六方密排形式，但单位面积原子数最多的却是 (110)。
误区 4：认为布拉格定律里的 θ 是入射角（与法线夹角）。 布拉格公式里的 θ 是入射线与晶面的夹角（掠射角）。 衍射仪报的 2θ 是入射线与衍射线的夹角，对应的正是 2×这个 θ。
误区 5：把"晶向 <100>"和"晶面 (100)"混为一谈。 硅片说 "(100) 片"指表面是 (100) 晶面，其法线方向是 [100]。 而沟道方向（源漏连线方向）常取 <110> —— 表面晶向与沟道晶向是两回事，别搞混。

15. 自测

自测 1：求晶面指数 —— 某晶面在 x、y、z 轴的截距分别为 1、1、∞（以 a 为单位），求其米勒指数；另一个晶面截距为 1、1、−1，求指数。
第一个：截距 (1, 1, ∞) → 取倒数 (1, 1, 0) → 已是最小整数比 → (110)。

第二个：截距 (1, 1, −1) → 取倒数 (1, 1, −1) → 整数化后负号写成上划线 → (111)，读作 "一一负一"。

关键提醒：必须取倒数、必须化到最小整数比、负数必须写成上划线而不是前置负号。 另外 (110) 在立方晶系中共 12 个等价面，构成 {110} 面族。
自测 2：已知硅 a = 5.431 Å，分别求 (100)、(110)、(111) 面的面间距 d 与面密度，并指出哪个面面密度最高。
面间距（dhkl = a/√(h²+k²+l²)）：
· d₁₀₀ = 5.431 / 1 = 5.431 Å
· d₁₁₀ = 5.431 / √2 = 3.840 Å
· d₁₁₁ = 5.431 / √3 = 3.135 Å

面密度（a² = 2.95×10⁻¹⁵ cm²）：
· (100)：2/a² = 6.78×10¹⁴ cm⁻²
· (110)：2√2/a² = 9.59×10¹⁴ cm⁻²
· (111)：4/(√3a²) = 7.83×10¹⁴ cm⁻²

最高的是 (110)，顺序为 (110) > (111) > (100)。

易错点：很多人凭"密排"直觉选 (111)，但 (111) 是六方密排的排列方式， (110) 才是单位面积原子数最多的面。可验证：(110) 面的二维重复单元是 a×(a/√2) 的矩形、含 2 个原子 —— 面积 a²/√2，密度 2÷(a²/√2) = 2√2/a²，与上式一致。
自测 3：为什么 MOS 器件几乎全部做在 (100) 面上，而不是面密度更高的 (110) 或 (111)？请从界面态、氧化速率、迁移率三个角度说明。
① 界面态密度（决定性因素）：Si(100)/SiO₂ 界面态密度约 10¹⁰ cm⁻²·eV⁻¹， 比 Si(111) 低约一个数量级。(100) 面每个表面 Si 原子有 2 个悬挂键，氧化时更容易形成完整的 Si–O–Si 桥接网络； (111) 面原子最密、氧化最快，反而留下更多未饱和键与应变缺陷。 界面态直接决定阈值电压稳定性、迁移率退化和 1/f 噪声，所以这一条是压倒性的。

② 氧化速率可控性：热氧化线性速率 (111) > (110) > (100)（约 1.68 : 1.25 : 1）。 先进节点栅氧只有 1~2 nm，(100) 速率慢反而便于精确控厚； (111) 太快，薄氧厚度均匀性和重复性都更难做。

③ 迁移率：电子迁移率在 (100) 面最高，NMOS 受益； 空穴迁移率确实在 (110) 面最高（约 2 倍），这是 (100) 的劣势。 工程上的补救办法不是换衬底，而是应变工程（SiGe 源漏、应力记忆层） 或把 PMOS 沟道做在 (110) 晶面上（如 FinFET 的侧壁），从而兼顾 (100) 的界面优势与 (110) 的空穴迁移率。

结论：衬底选 (100) 是界面质量优先的全局最优；空穴迁移率的短板用应变与结构创新单独补。
自测 4：用 KOH 刻蚀 (100) 硅片上的方形窗口，最终得到什么形貌？侧壁晶面是什么？若窗口边长 W，刻蚀深度 D 是多少？
形貌：得到一个倒金字塔（或 V 型槽）—— 掩膜窗口处向下刻， 四个侧壁自动停在 (111) 面上。(100) 片上的四个 <110> 方向解理/慢刻面围成正四棱锥。

侧壁晶面：{111}。原因是 KOH 对 (111) 的刻蚀速率比 (100) 慢两个数量级（可达 100:1 以上）， (111) 成为"自停止面"。

深度与角度：(100) 与 (111) 面的夹角为 arccos(1/√3) = 54.74°（用法向量点积 (001)·(111)/(|..|) = 1/√3 得到）。 因此若窗口边长为 W，刻蚀深度 D = (W − W') / 2 × tan54.74° = (W − W') × √2 / 2， 其中 W' 是刻到底部时的底边宽度；若刻穿成完整倒金字塔（尖端收拢），则 D = W × √2 / 2 ≈ 0.707 W。

工程意义：刻蚀会自动停在几何确定的深度，不依赖时间控制， 这正是 MEMS 里做硅杯、V 型槽、自停止膜的依据；反过来也可以用它来精确反推膜厚。
