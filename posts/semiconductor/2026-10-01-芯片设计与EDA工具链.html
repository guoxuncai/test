1. 数字 IC 设计全流程

阶段输入 → 输出核心任务典型工具
架构/规格需求 → 微架构文档模块划分、性能指标、接口定义—
RTL 设计文档 → HDL 代码用硬件描述语言写出电路行为编辑器 / HDL 辅助
功能验证RTL → 覆盖率报告仿真、随机激励、断言、形式验证VCS / Xcelium / Verilator
逻辑综合RTL + 约束 → 门级网表映射到标准单元，优化时序/面积/功耗Design Compiler / Yosys
DFT网表 → 带测试结构的网表扫描链、BIST，提高可测性与良率筛查Tessent / Modus
布局布线 P&R网表 + 单元库 → 版图Floorplan / Placement / CTS / RoutingInnovus / ICC2 / OpenROAD
签核 Signoff版图 → 各类检查报告STA、DRC、LVS、功耗、IR-drop、EMPrimeTime / Calibre
流片 Tape-out版图 → GDSII / OASIS交付代工厂，通常还需 MPW 拼版—
流片（Tape-out）是不可逆的。一次先进节点流片的掩膜费用可达数百万到上千万美元， 周期 2~3 个月。因此"签核"环节的严谨性直接决定项目生死 —— 这也是 EDA 工具价值极高的原因。

2. 模拟 IC 流程有什么不同

维度数字 IC模拟 IC
设计方式HDL 描述 + 高度自动化手工设计电路拓扑与器件尺寸为主
自动化程度高（综合、APR 全自动）低（版图仍大量手工，靠经验）
关键约束时序、功耗、面积增益、带宽、噪声、失配、线性度、PSRR
版图要点拥塞、时序、可制造性匹配（共质心、交叉耦合）、对称、保护环、Dummy
工艺敏感度相对不敏感极敏感，换工艺往往要重新设计
迭代成本主要靠仿真收敛常需多次流片迭代（硅验证）
为什么模拟工程师稀缺？数字设计有成熟的方法学和工具链，经验可复用； 模拟设计高度依赖对器件物理、寄生效应与工艺细节的直觉，培养周期长、难以完全自动化。 这也是模拟 IP（SerDes、PLL、ADC、PMIC）长期保持高价值的原因。

3. PPA：一切权衡的中心

Performance
性能：频率、延迟、吞吐
Power
功耗：动态 + 静态
Area
面积：直接决定成本
三者互相拉扯：提高频率通常要加大驱动（面积↑、功耗↑）； 降低电压能省功耗但速度变慢、噪声容限变小；缩小面积可能牺牲性能与可制造性。 芯片架构评审的本质，就是在给定应用场景下为 PPA 排序 —— 例如手机 SoC 优先功耗，服务器 CPU 优先性能，MCU 优先成本。

4. PDK：代工厂给你的"说明书"

PDK（Process Design Kit，工艺设计包）是设计与制造之间的契约，通常包含：

内容作用
器件 SPICE 模型仿真用的 MOSFET/电阻/电容模型（含工艺角 Corner）
DRC 规则文件设计规则检查：线宽、间距、密度等可制造性约束
LVS 规则文件版图与电路图一致性检查
标准单元库时序库（.lib，含各 PVT 角）、物理库（.lef）、门级网表
层定义与技术文件每层的名称、颜色、用途（供版图工具识别）
寄生提取规则从版图提取 R/C，用于后仿真与时序签核
PDK 是严密的商业机密。获取主流代工厂（台积电、三星、中芯国际等）的 PDK 需要签署 NDA， 这也是个人爱好者此前难以接触真实流片的原因。开源 PDK（如 SkyWater SKY130）的出现改变了这一局面。

5. 签核：tape-out 前的最后关

检查项查什么失败的代价
STA 静态时序在所有 PVT 角下建立/保持时间是否都满足芯片跑不到目标频率，或功能随机出错
DRC版图是否违反代工厂设计规则流片直接失败或良率极低
LVS版图连线是否与电路网表一致电路连接错误，芯片不工作
天线效应 Antenna制造过程中长金属线收集电荷是否击穿栅氧栅氧损伤，可靠性下降甚至直接失效
IR-drop / EM电源网络压降、金属线电迁移局部电路供电不足或长期可靠性问题
金属密度 Dummy各层金属覆盖率是否满足 CMP 要求抛光不均匀，影响后续层光刻对焦
功耗与热峰值功耗、热密度分布过热降频、封装与散热成本失控
工艺角（Corner）的含义：SS（慢 NMOS + 慢 PMOS）、FF（都快）、SF/FS（混合）、TT（典型）。 签核必须保证所有角都满足时序 —— 芯片出厂后要能适应不同批次、电压与温度， 这也是为什么同一款芯片会有"体质"差异（超频/降压能力不同）。

7. 零成本上手：开源工具链

推荐新手的完整开源链路（对应路径地图第一、二阶段）：
① SKY130 PDK（SkyWater 130nm 开源工艺）　→ ② Xschem / Schematic 画原理图　→ ③ ngspice 做电路仿真　→ ④ Magic / Klayout 画版图与 DRC　→ ⑤ Netgen 做 LVS　→ ⑥ Yosys + OpenROAD（OpenLane） 跑通数字全流程　→ ⑦ 通过 Efabless / ChipIgnite 报名开源 MPW 流片
建议项目难度能练到什么
反相器链 + 环形振荡器★原理图、仿真、版图、DRC/LVS 全流程
带隙基准 Bandgap★★器件匹配、温度系数、启动电路
运算放大器（两级 / 折叠式）★★★增益带宽、相位裕度、补偿与失配

学习建议：先跑通"反相器 → 环形振荡器"这条最短闭环（第 1~2 周即可完成）， 拿到 DRC/LVS 全绿的结果，再逐步加难度。完整闭环跑通一次，比看十遍资料都管用 —— 这也正是路径地图里"推荐新手第一个项目"的设计意图。

8. 自测

自测 1：逻辑综合的输入和输出分别是什么？为什么它对数字设计如此关键？
输入是 RTL 代码 + 时序/面积/功耗约束（SDC）+ 标准单元库；输出是门级网表。 它是"行为描述"到"物理可实现电路"的分水岭 —— 综合结果直接决定了后续时序收敛的难度， 也是第一次能拿到较准确的面积与功耗估算的环节。
自测 2：DRC 和 LVS 分别查什么？为什么两者都要过？
DRC 检查版图是否符合代工厂的几何规则（线宽、间距、密度），回答"能不能造"； LVS 检查版图提取出的电路网表是否与原理图一致，回答"造出来是不是你要的电路"。 二者正交：一个版图可能完全符合设计规则，却把连线接错了；也可能连接正确但违反间距无法制造。所以必须都过。
自测 3：为什么芯片要做"工艺角（PVT Corner）"签核，而不是只在典型条件下验证？
实际制造中，每片晶圆、每个批次的晶体管参数都有统计波动（Process）， 使用时电压会波动（Voltage）、温度会变化（Temperature）。 如果只按典型条件验证，量产后必然有一部分芯片在极端条件下失效， 良率无法保证。因此必须在 SS（最慢）、FF（最快）等最坏角下都满足时序，才算签核通过。
