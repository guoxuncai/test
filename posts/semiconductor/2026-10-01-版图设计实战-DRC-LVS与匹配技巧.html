1. 版图是什么

版图（Layout）是芯片的几何描述：用多层多边形告诉工厂"哪里留硅、哪里刻掉、哪里铺金属、哪里打孔"。 它直接对应制造时的掩膜（Mask），最终输出 GDSII / OASIS 文件交付代工厂。

一句话理解版图与电路的关系：电路图（Schematic）定义连什么，版图定义怎么摆放、怎么连线、多大尺寸。 同样的电路，版图画得好不好，性能可以差出一个数量级 —— 这正是模拟版图工程师的价值所在。

2. 必须认识的工艺层

层（常见缩写）含义作用
NW / PWN 阱 / P 阱定义衬底类型，PMOS 做在 N 阱里
OD / AA / DIFF有源区（扩散区）可以做晶体管的区域，之外都是场氧隔离
PO / POLY多晶硅栅极；也可做电阻、短距离连线
PP / NP（注入层）P+ / N+ 注入区分源漏的掺杂类型
CT / CO（接触孔）Contact连接有源区/多晶硅与第 1 层金属
M1 … Mn金属层互连线；层数随工艺递增（先进工艺 10+ 层）
VIA1 … VIAn-1通孔连接相邻两层金属
IM / Metal 选项层识别层 / 电阻层用于器件识别或特殊器件（电阻、电容、二极管）
记忆方法：纵向"搭楼梯"—— 有源区/多晶硅 → 接触孔 → M1 → VIA1 → M2 → VIA2 → M3 …， 每一级只能和相邻级相连。这也是版图工具里"打孔串层"必须一层层来的原因。

把这些层"竖着切开"看一眼，会比表格直观得多。下图左边是器件剖面， 右边是各层的连接层级 —— 注意金属层只能通过通孔与相邻层相连， 不存在"M1 直接跳到 M3"这种走法。

层名字在不同 PDK 里不一样。Sky130 里叫 li1 / met1 / via， 商用 PDK 里可能叫 M1 / VIA1 / OD / PO。名字不重要， 重要的是看懂层与层之间的连接关系：新拿一个 PDK，第一件事就是翻它的层定义表。

3. 设计规则在约束什么

设计规则（Design Rule）是代工厂根据工艺能力给出的几何约束。违反它，芯片造不出来或良率极低。

规则类型含义典型例子
最小宽度 Width线条或图形不能太窄M1 最小线宽 0.14 μm
最小间距 Space同层图形之间不能太近M1 间距 0.14 μm
包围 Enclosure上层图形要把下层完全包住接触孔四周 M1 至少包 0.03 μm
延伸 Extension栅极两侧有源区要伸出去PO 两侧 OD 至少延伸 0.18 μm
面积 Area图形不能太小以免脱落M1 最小面积 0.02 μm²
密度 Density各层覆盖率需落在区间内M1 密度 20%~80%，不足要填 Dummy

这六类规则看着抽象，其实每一条都对应一个具体的物理后果。下面把最常见的四条画出来 —— 左边是违反的样子，右边是合格的样子。

规则不是"越小越牛"，而是"工艺窗口"。代工厂给的最小线宽， 是它在良率、产能、可靠性之间权衡后给出的安全边界：再小 10 nm， 也许实验室里能刻出来，但量产后良率会从 95% 掉到 60%。 所以"能不能画"和"能不能量产"是两件事 —— 设计规则管的是后者。
为什么必须填 Dummy（虚拟图形）？CMP 抛光时，金属稀疏的区域会被磨得更多（Dishing）、 密集区域磨得少，导致表面高低不平，后续光刻对焦失败。因此需要往空白处填不与电路连接的金属块， 让整层密度均匀。先进工艺下 Dummy 由工具自动插入，但要注意它引入的额外寄生电容。

4. 四种检查：DRC / LVS / ERC / PEX

检查全称回答的问题不过的后果
DRCDesign Rule Check几何上能不能造流片失败或良率极低
LVSLayout vs Schematic连出来是不是你要的电路连接错误，功能不对
ERCElectrical Rule Check有没有电学违规（浮空节点、衬底未接等）潜在的可靠性与功能隐患
PEXParasitic Extraction实际有多大寄生 R/C后仿真与实测对不上

电路图里一根线就是一根线，没有电阻也没有电容；但版图里每一段金属都是电阻， 每条线对面都有一块衬底构成电容，两条相邻的线之间还互相耦合。 PEX 做的事，就是把这些"画出来的副作用"全部量化回网表。下图是四类主要寄生来源：

寄生类型典型量级主要影响缓解手段
金属对地电容 Cg0.1 ~ 0.2 fF/μm带宽下降、建立时间变长缩短走线、用顶层厚金属、减小线宽
线间耦合电容 Cc与间距成反比串扰（Crosstalk）、信号完整性加大间距、插屏蔽线（Shielding）
通孔电阻 Rvia1 ~ 5 Ω/个电源网络 IR-drop、高频衰减多孔并联、关键路径少打孔
扩散区结电容 Cj与结面积/周长成正比限制最高工作频率减小漏/源面积、折叠器件
流程顺序不能乱：DRC 全绿 → LVS 匹配 → PEX 提取寄生 → 后仿真（Post-layout Simulation）。 很多新手只做前仿真就以为万事大吉，回片后却发现带宽差一倍 —— 差的往往就是那几十 fF 的寄生电容。

5. 匹配：模拟版图的灵魂

电流镜、差分对、带隙基准这类电路，要求两个"标称相同"的器件真的相同。 但工艺存在系统性梯度（掺杂、温度、应力在硅片上的分布不均），所以要用版图技巧抵消：

技巧做法抵消什么
共质心 Common-centroid两器件拆成若干单元，交叉对称摆放，使两者的"重心"重合线性梯度（沿 x 或 y 方向的工艺变化）
交叉耦合 Cross-couplingA/B/A/B 交替排列一阶梯度
同向 Same orientation所有器件朝向一致各向异性效应（离子注入角度、晶向）
Dummy 器件在阵列两端加不接入电路的相同器件边缘刻蚀负载效应（边缘与中间刻蚀速率不同）
保护环 Guard Ring用重掺杂环包围敏感器件并接到固定电位衬底噪声耦合与闩锁
加大器件面积WL 增大随机失配（失配 ∝ 1/√(WL)）
σ(ΔVt) ≈ AVt / √(W · L) 随机失配随器件面积平方根下降。想让失配减半，面积要增大 4 倍 —— 这是精度与面积之间最直接的权衡。

6. 匹配进阶：WPE 与 STI 应力

到第 5 节为止，我们抵消的都是位置带来的梯度——工艺参数在硅片上缓慢地线性变化。 但还有一类失配来源更隐蔽：器件自身的参数，会被它周围画了什么改变。 这类效应统称版图依赖效应（LDE, Layout Dependent Effects），最典型的就是 WPE 与 STI 应力。 它们的特点是：电路图完全一样、W/L 完全一样，只因为摆在版图上的位置不同，实测电流就能差出百分之几。 对高精度电流镜、带隙基准、比较器来说，这已经足够让指标报废。

效应物理成因受哪个版图量控制对策
WPE 阱邻近效应阱注入时离子从光刻胶与阱边缘侧向散射，靠边的器件掺杂偏多器件到阱边界的距离 S匹配对保持等距；敏感器件远离阱边
STI 应力 / LOD浅槽隔离氧化物体积膨胀，横向挤压沟道晶格，改变迁移率栅到有源区边界的距离 SA / SB匹配对 SA、SB 完全一致；两端加 Dummy 撑开
金属与封装应力上层金属、钝化层、塑封体施加的机械应力改变迁移率器件在芯片上的位置、周边金属密度共质心摆放；远离功率器件与切割道
片上温度梯度功率器件发热导致硅片温度不均与热源的距离和相对方向对称布局；敏感对放在同一等温线上
新手最容易踩的坑：画了一对非常漂亮的共质心器件，结果一边紧挨阱边、一边在阱中央。 共质心只抵消了线性梯度，却同时引入了WPE 的系统偏差——两者不是一回事，不能互相替代。 正确的优先顺序是：先保证 LDE 环境一致（S、SA、SB 都相同），再谈共质心排列。
为什么前仿真里看不到这些？因为标准 SPICE 模型只认 W 和 L 两个参数， 而 WPE / STI 效应必须靠版图后仿真才能体现：先由 PEX 工具把版图里测出的 S、SA、SB 反标（back-annotate）回网表，仿真器才会用修正后的器件参数。 这也是"LVS 通过"与"仿真结果可信"之间还隔着一步的原因。

7. 天线效应

成因：制造过程中，等离子刻蚀会让大面积的金属线像"天线"一样收集电荷。 若这些电荷通过与之相连的栅极泄放，就会击穿极薄的栅氧化层，造成永久损伤。

天线比 = 连接到栅极的金属面积 / 栅氧化层面积　（工艺给出上限，如 400:1）

理解了图 6 之后再看下面这张表，每一行对应的就不再是一句"规则要求"，而是一个明确的物理动作：

解决方法做法代价
跳线（Jumper）长金属在中途跳到上层再跳回来，断开连续收集面积增加通孔与电阻
天线二极管在栅极旁接一个到衬底的二极管提供泄放通路增加寄生电容与面积
调整布线顺序先布靠近栅极的短金属，最后接大面积金属布线约束
天线效应 DRC 不过是最常见的回片杀手之一。它不影响电路逻辑、仿真也完全正常， 却会在制造阶段批量损伤栅氧 —— 因此必须靠专门的 Antenna DRC 规则拦截，不能只看普通 DRC。

8. 闩锁效应 Latch-up

CMOS 结构中天然存在寄生的可控硅（SCR）：由寄生 NPN 与 PNP 互相耦合形成正反馈。 一旦被触发（如 I/O 上的电压过冲），就会在电源与地之间形成低阻通路，电流剧增直至烧毁芯片。

关键在于，这两个三极管不是画出来的，而是 CMOS 结构自带的： NMOS 的 N+ 源、P 衬底、N 阱恰好构成一个纵向 NPN；PMOS 的 P+ 源、N 阱、P 衬底恰好构成一个横向 PNP。 它们共用衬底与阱，于是互相提供基极电流，形成一个谁也离不开谁的正反馈环。 下图左边是剖面对应关系，右边是这条环路在电流-电压上的"指纹"——一条带负阻区的回滞曲线。

防护措施原理
保护环 Guard Ring在 NMOS 周围加 P+ 环接地、PMOS 周围加 N+ 环接 VDD，收集少子、降低寄生电阻
加大衬底/阱接触密度降低寄生电阻 Rsub/Rwell，提高触发门槛
拉开 NMOS 与 PMOS 间距降低寄生双极管的电流增益
ESD 保护器件在 I/O 加钳位二极管与电源钳位，防止过冲触发
设计规则里"衬底接触间距"不是形式主义。它直接决定寄生电阻大小， 也就决定了闩锁触发电流门槛。I/O 区域因为要抗 ESD，规则通常比内部电路更严格。
闩锁不是"自己发生"的，总要有人推一把。常见的触发源有四类： ① I/O 引脚上的电压过冲/下冲（超过 VDD 或低于 VSS 一个二极管压降）； ② ESD 事件注入的瞬态大电流； ③ 电源上电顺序不当（I/O 先于内核得电）； ④ 高温与辐照环境下寄生电阻升高、β 变大。 这也是为什么所有 I/O 单元都要单独做闩锁加固 —— 它们离"外界"最近。
一个实用的判断顺序：拿到一个 PDK，先看它给的 Latch-up 规则（衬底/阱接触的最大间距、I/O 与内部电路的间隔）； 画版图时先铺好保护环与接触阵列再放器件，而不是画完了再补 —— 后者几乎总会因为空间不够而被迫牺牲规则。

9. 实战：画一个反相器版图

建议的上手顺序：① 用 Xschem / 原理图工具画反相器 → ② ngspice 仿真验证直流与瞬态 → ③ Magic 或 Klayout 画版图 → ④ 跑 DRC（Sky130 规则）→ ⑤ Netgen 做 LVS → ⑥ 提取寄生做后仿真。走完这六步，你就完整跑通了一次"设计 → 验证 → 物理实现"的闭环。
新手版图十错（自查清单）：
① 衬底/阱接触忘画或太稀疏 → 闩锁风险；
② 接触孔数量不足 → 电流密度过大、电迁移；
③ 器件朝向不一致 → 失配；
④ 敏感差分对未做共质心 → 失调电压大；
⑤ 长金属线直连栅极 → 天线效应；
⑥ 忘了 Dummy → 刻蚀负载不均；
⑦ 金属密度不达标 → CMP 不平；
⑧ 未标注器件识别层 → LVS 认不出器件；
⑨ 电源/地线宽度不足 → IR-drop 与电迁移；
⑩ 只做前仿真就交付 → 回片性能与仿真严重不符。

10. 自测

自测 1：DRC 全绿、LVS 也通过，为什么还要做 PEX 后仿真？
因为版图引入了前仿真中没有的寄生电阻与电容：金属线电容、通孔电阻、结电容、线间耦合电容等。 在高速或高精度电路中，几十 fF 的寄生就足以让带宽、建立时间、失调电压显著偏离设计值。 PEX 后仿真是"设计与实测能否对得上"的最后一道保险。
自测 2：某电流镜失配超标，在不改电路的前提下有哪几种版图手段？
① 改用共质心（ABBA）排列，抵消一阶工艺梯度；② 两端加 Dummy，消除边缘刻蚀差异； ③ 增大 W·L（失配 ∝ 1/√WL）；④ 保证两器件同朝向、同环境（周围图形对称）； ⑤ 关键的还可加保护环隔离噪声。通常优先做①③，性价比最高。
自测 3：天线效应的本质危害是什么？为什么仿真发现不了？
危害是制造过程中大面积金属收集的电荷通过栅极泄放，击穿薄栅氧，造成永久性损伤。 仿真发现不了，是因为它并非电路工作时的电学行为，而是制造过程中的物理现象 —— 电路网表与 SPICE 模型里根本没有"等离子充电"这项，只能靠几何规则（天线比）来检查。
自测 4：版图里"Dummy"这个词出现了两次（金属 Dummy 和器件 Dummy），它们分别解决什么问题？
两者目的完全不同。金属 Dummy 是为了满足密度规则：CMP 抛光时金属稀疏处会被磨得更深（Dishing）， 填 Dummy 让整层密度均匀，保证表面平整、后续光刻能对准 —— 它不接任何电路，代价是引入额外寄生电容。 器件 Dummy 是为了匹配：在器件阵列两端放不接入电路的相同器件，让中间器件处在相同的刻蚀环境里， 消除边缘刻蚀负载效应，同时撑开 SA/SB 距离使 STI 应力一致。前者管"能不能造"，后者管"造出来准不准"。
自测 5：两个器件 W/L 完全相同，也认真做了共质心排列，为什么实测电流仍可能差百分之几？
因为共质心只抵消了线性工艺梯度，还有一类版图依赖效应（LDE）它管不了： ① WPE —— 器件到阱边的距离 S 不同，阱注入的离子侧向散射量就不同，Vt 与 μ 随之偏移； ② STI 应力 / LOD —— 栅到有源区边界的 SA、SB 不同，沟道受到的挤压应力不同，迁移率不同； ③ 上层金属与封装应力、片上温度梯度。 对策是先保证 LDE 环境一致（S、SA、SB 全部相同，必要时加 Dummy 器件撑开），再做共质心， 并且要用带反标参数的版图后仿真来验证，前仿真看不到这些效应。
自测 6：闩锁一旦触发，为什么撤掉触发信号也没用？版图上如何提高触发门槛？
因为闩锁是一个正反馈自持过程：寄生 NPN 与 PNP 互相提供基极电流， 只要环路增益 β₁·β₂ ≥ 1，即使外部扰动消失，环路自己也能维持导通 —— 在 I–V 曲线上表现为越过了触发点、 落入负阻区右侧的自锁状态。要退出必须把电压/电流降到维持点以下，通常只能断电。 版图上提高门槛的手段：① 加密衬底/阱接触，减小寄生电阻 Rsub、Rwell， 使基极电压难以被抬高；② 加保护环（NMOS 周围 P+ 环接地、PMOS 周围 N+ 环接 VDD）收集少数载流子； ③ 拉开 NMOS 与 PMOS 间距降低 β；④ I/O 加 ESD 钳位器件防止过冲。
