🧪 半导体器件新手行动清单

📝 前言：这份清单写给谁、怎么用

这是一份面向微电子、集成电路相关专业学生以及计划转入半导体行业工程师的行动清单。 它回答一个具体的问题：从今天开始，如何在约四个月内走完"理论 → 仿真 → 版图 → 流片 → 测试"的完整闭环， 让你对芯片的理解不再停留在课本公式，而是亲手拿到过一颗自己参与设计的芯片。

使用方式：① 按四个阶段顺次推进，每个阶段内部的勾选项即每周任务； ② 阶段卡片底部附有本站配套笔记，理论卡壳时点击即可回到对应专题深入； ③ 用文末「技能进度自测表」每月复盘，勾选状态就是你的真实进度。 流片周期不受人控制，但等待期恰好是第四阶段理论学习的好窗口——清单已按此排布。

✅ 第一阶段：理论基础与软件环境（第1-4周）
📚 半导体物理核心
✔ 完成《半导体物理》(刘恩科/施敏) 前5章：能带、载流子、PN结
✔ 观看慕课：国家智慧教育平台“半导体器件物理”
✔ 熟记公式：内建电势、耗尽层宽度、二极管I-V、MOSFET阈值电压
🖥️ 安装免费EDA工具
✔ Klayout (版图查看/编辑) — 官网下载并熟悉界面
✔ Ngspice / LTspice — 完成一个二极管整流仿真
✔ 安装 Python + PySpice (用于自动化仿真)
📄 阅读PDK文档
✔ 下载开源PDK: SkyWater 130nm (GitHub)
✔ 理解设计规则文档 (DRM) 关键条款
✔ 了解MPW服务: Efabless, Google ChipIgnite
📖 本阶段配套笔记（理论卡壳时点开复习）： 固体物理基础 · 晶格/晶向/晶面 半导体物理基础 · 能带与载流子 PN 结原理与特性
✅ 第二阶段：器件仿真与版图入门（第5-8周）
⚙️ TCAD入门
✔ 安装免费/试用版: Silvaco TCAD Student, Lumerical Student, 或 Sentaurus 教学版
✔ 跑通官方PN结示例 (电流-电压特性)
✔ 修改掺杂浓度，观察击穿电压变化
🎨 版图实战
✔ 用Klayout绘制简单MOSFET版图 (源、漏、栅、接触孔)
✔ 运行DRC (使用Sky130规则文件)
✔ 提取寄生参数 (使用开源Magic或Klayout+netgen)
📊 模型提取练习
✔ 用LTspice拟合二极管SPICE模型 (Rs, N, Is)
✔ 尝试用QucsStudio进行小信号增益仿真
📖 本阶段配套笔记（仿真建模前先吃透器件）： MOSFET 工作原理与特性曲线 CMOS 集成电路基础 版图设计实战 · DRC/LVS
✅ 第三阶段：流片准备与第三方对接（第9-12周）
🚀 MPW申请
✔ 注册Efabless平台，了解ChipIgnite流程 (150美元起)
✔ 准备设计文档、GDSII、引脚说明
✔ 联系国内MPW代理: 中科院微电子所MPW中心 / 摩尔精英
🤝 设计服务咨询
✔ 获取欣峰扬科技/创意电子报价 (版图外包或全流程)
✔ 签署NDA，获取目标代工厂PDK (TSMC, 中芯国际, 华虹)
✔ 学习PDK中的器件模型与DRC/LVS规则
📋 流片签核清单
✔ GDSII完整性检查
✔ 天线效应检查 (Antenna rule)
✔ 金属密度填充验证 (Dummy fill)
📖 本阶段配套笔记（理解你的设计将被如何制造）： 芯片制造工艺流程详解 芯片设计流程与 EDA 工具链 硅单晶生长与衬底制备
✅ 第四阶段：实验验证与表征（第13-16周·收到芯片后）
🔌 电学测试准备
✔ 联系第三方测试实验室 (华测蔚思博/广电计量/胜科纳米) 预约探针台+参数分析仪时间
✔ 准备PCB测试夹具或探针卡 (可找季丰电子定制)
✔ 学习使用Keysight B1500 / Keithley 4200 基础操作
📈 典型测试项
✔ 输出特性 (Id-Vds)
✔ 转移特性 (Id-Vgs) 提取Vt、跨导
✔ 击穿电压、漏电流、C-V曲线
🔬 失效分析与可靠性
✔ 委托扫描电镜 (SEM) 观察器件截面
✔ 做高温存储/温度循环实验 (可外包)
✔ 撰写测试报告，对比仿真与实测差异
📖 本阶段配套笔记（测试与良率的工程背景）： 芯片封装、测试与失效分析 CMP 平坦化、量测与良率控制
✅ 第五阶段：进阶方向与视野扩展（长期）
🧭 选定细分方向
✔ 数字/模拟/射频/功率/存储各有不同知识图谱，回看自测表里最强的那几项
✔ 功率方向 → SiC/GaN 宽禁带器件；存储方向 → DRAM/NAND 阵列结构
✔ 订阅 1-2 个方向的技术期刊（IEDM/VLSI 会议摘要即可）
🌐 建立产业视角
✔ 理解 IDM / Fabless / Foundry / OSAT 的分工与各自盈利模式
✔ 能手算一颗 die 的成本：掩模 NRE、良率、面积三者如何决定毛利
✔ 能讲清一颗芯片从需求到量产的完整时间轴，知道自己做的事在哪一段
✔ 跟踪先进封装与 Chiplet 趋势：后摩尔时代的新赛道
✔ 关注摩尔定律演进：FinFET → GAA → 背面供电的路线图
💼 理解生意与岗位
✔ 分清 EDA 订阅、IP 授权费、版税这些「不造芯片也赚钱」的模式
✔ 对照岗位地图定位：架构/前端/验证/DFT/后端/版图/模拟/工艺/良率/封测/FA
✔ 判断自己喜欢「从零创造」还是「诊断问题」，偏好抽象还是实体
🤝 积累行业连接
✔ 把第一次流片+测试写成技术博客或报告（求职作品）
✔ 参加开源芯片社区（如 Efficient Electronics Challenge 类活动）
✔ 实习优先选择能摸到真实 PDK 与机台的岗位
📖 本阶段配套笔记（从工程师视角回到产业全景）： 摩尔定律与器件微缩 半导体材料全景 · SiC/GaN 存储器 · DRAM/NAND 先进封装与 Chiplet 半导体设备与产业链 产业分工与商业模式 晶圆厂经济学与成本模型 一颗芯片的诞生全流程
