🧪 半导体器件新手行动清单

从零到实验验证 · 每月可执行步骤 · 工具/资源/第三方对接全攻略

📖 理论学习 → 💻 软件安装 → 📐 仿真练习 → 🎨 版图设计 → 🚀 MPW流片 → 🧪 实验测试
✅ 第一阶段：理论基础与软件环境（第1-4周）
📚 半导体物理核心
✔ 完成《半导体物理》(刘恩科/施敏) 前5章：能带、载流子、PN结
✔ 观看慕课：国家智慧教育平台“半导体器件物理”
✔ 熟记公式：内建电势、耗尽层宽度、二极管I-V、MOSFET阈值电压
🖥️ 安装免费EDA工具
✔ Klayout (版图查看/编辑) — 官网下载并熟悉界面
✔ Ngspice / LTspice — 完成一个二极管整流仿真
✔ 安装 Python + PySpice (用于自动化仿真)
📄 阅读PDK文档
✔ 下载开源PDK: SkyWater 130nm (GitHub)
✔ 理解设计规则文档 (DRM) 关键条款
✔ 了解MPW服务: Efabless, Google ChipIgnite
✅ 第二阶段：器件仿真与版图入门（第5-8周）
⚙️ TCAD入门
✔ 安装免费/试用版: Silvaco TCAD Student, Lumerical Student, 或 Sentaurus 教学版
✔ 跑通官方PN结示例 (电流-电压特性)
✔ 修改掺杂浓度，观察击穿电压变化
🎨 版图实战
✔ 用Klayout绘制简单MOSFET版图 (源、漏、栅、接触孔)
✔ 运行DRC (使用Sky130规则文件)
✔ 提取寄生参数 (使用开源Magic或Klayout+netgen)
📊 模型提取练习
✔ 用LTspice拟合二极管SPICE模型 (Rs, N, Is)
✔ 尝试用QucsStudio进行小信号增益仿真
✅ 第三阶段：流片准备与第三方对接（第9-12周）
🚀 MPW申请
✔ 注册Efabless平台，了解ChipIgnite流程 (150美元起)
✔ 准备设计文档、GDSII、引脚说明
✔ 联系国内MPW代理: 中科院微电子所MPW中心 / 摩尔精英
🤝 设计服务咨询
✔ 获取欣峰扬科技/创意电子报价 (版图外包或全流程)
✔ 签署NDA，获取目标代工厂PDK (TSMC, 中芯国际, 华虹)
✔ 学习PDK中的器件模型与DRC/LVS规则
📋 流片签核清单
✔ GDSII完整性检查
✔ 天线效应检查 (Antenna rule)
✔ 金属密度填充验证 (Dummy fill)
✅ 第四阶段：实验验证与表征（第13-16周·收到芯片后）
🔌 电学测试准备
✔ 联系第三方测试实验室 (华测蔚思博/广电计量/胜科纳米) 预约探针台+参数分析仪时间
✔ 准备PCB测试夹具或探针卡 (可找季丰电子定制)
✔ 学习使用Keysight B1500 / Keithley 4200 基础操作
📈 典型测试项
✔ 输出特性 (Id-Vds)
✔ 转移特性 (Id-Vgs) 提取Vt、跨导
✔ 击穿电压、漏电流、C-V曲线
🔬 失效分析与可靠性
✔ 委托扫描电镜 (SEM) 观察器件截面
✔ 做高温存储/温度循环实验 (可外包)
✔ 撰写测试报告，对比仿真与实测差异
